# Reference screens

Screens taken from `docs/design/mockup.html` on 2026-11-08 for reference (1440x900 viewport, 1.5x, the app window with the
menu bar). Each has a light and a `-dark` variant. The running app is authoritative where they differ.

| Image | Shows |
| --- | --- |
| `01-start` | Main window on start: inbox sidebar, preview of the selected payslip, filing panel with recent destinations. |
| `02-search` | Destination search for "gehalt 33": filtered results with match highlights and the folder's contents below. |
| `03-drill` | Stepped into the Hund Fritzi folder: path bar, "this folder" row, subfolders. |
| `04-new-folder` | Creating a new folder: inline name row inside Reisen with the "Creates ..." hint. |
| `05-name-hint` | Name field edited, Move button with the ⌘Return key-cap, and the "Press ⌘Return to move" toast after Return. |
| `06-conflict` | Name-conflict sheet with Keep Both (default), Cancel and Replace. |
| `07-filed` | A filed file selected: "Filed to ..." strip with Move Back, destination and name editable for renaming. |
| `08-trashed` | A trashed file: struck-through row, "Moved to Trash" strip with Put Back, status bar with Undo. |
| `09-history` | History window with date-grouped entries, side preview and actions. |
| `10-settings` | Settings window (Folders): archive folder and inbox table. |
