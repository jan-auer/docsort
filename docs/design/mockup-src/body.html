docsort Interactive UX mockup · main window

docsort is a Mac app that files documents from your inbox folders (Web-Downloads, Scanner) into your archive folder tree, with a large preview beside the filing panel and every step on the keyboard.

Try this (click the window first)

  1. Margit’s September payslip Gehaltszettel_2033-09… is selected. Just type gehalt 33 (typing in the sidebar goes to the destination filter), Tab to choose, ⌥↑ takes the newest name in the folder; change 08 to 09. Return only shows a brief toast; ⌘Return (the key-cap on the Move button) moves. The row stays with a check; the next file is selected.
  2. Conflict: with Ilmnet Rechnung Oktober 2033 (1) selected, type ilm rech, Tab, type 2033-10-04 rechnung oktober, ⌘Return. Keep Both is the default. Then ⌘Z / ⇧⌘Z.
  3. Browse: type hund, → steps into Hund Fritzi; its first row, this folder, is highlighted, so Tab would choose Hund Fritzi itself. ↓ → goes deeper (also into a folder without subfolders), ← back out; type inside a folder to filter its subtree; ⌫ in an empty filter steps out. ⇧Tab goes back a step, Esc clears.
  4. New folder: type reisen, ⇧⌘N (or ⌃⇧N, or the folder button under the list), type 2033-11 Besuch Westerholm/Bahn, Tab, ⌘Return. A filter that matches nothing offers New Folder “…” in the folder you are in.
  5. Filed file: select the checked 2033-10-20 Verlängerung Jahreskarte… row, Tab Tab, edit the name, ⌘Return renames it. ↺ or ⇧⌘R reverts; Rename stays disabled until something changes. Move Back sits in the green strip at the top of the panel (⌥⌘Z). Click a file in Folder contents to copy its name.
  6. Click the triangle of Uni Westerholm Herbst 2033. Space for Quick Look, ⌘⌫ moves to the Trash, right-click a row for its menu.
  7. History at the bottom of the sidebar (or ⌘Y, ⌃Y) opens History; ⌘/ lists every shortcut. Try the State buttons, and the Simulate buttons for changes made outside docsort: the list updates live without moving the selection.
